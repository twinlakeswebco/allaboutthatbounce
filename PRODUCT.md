# Product
<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
User-specified plain HTML, CSS, vanilla JavaScript; Cloudflare Workers static assets, no CMS.
## Users
Phone users requesting inflatable rentals; owner Rena Arnold managing requests and inventory.
## Product Purpose
Simple rentals in the La Grange, Kentucky area; a request becomes booked only after owner confirmation.
## Capabilities and Constraints
Four public pages and a separate admin. API mock in one module; localStorage demonstration. Cash/check. Private origin never client-visible. No street address published. Real photos, unit inventory, logo, policies, and brand colors undecided.
## Brand Commitments
Playful, bubbly, colorful, clean; mobile first, 360px. Large tap targets, strong contrast, no unnecessary remote dependencies.
## Evidence on Hand
Owner discussion supplied. All inventory, reviews, and policy copy must be labeled placeholders. Uploaded private reference material must never be served as static assets.
